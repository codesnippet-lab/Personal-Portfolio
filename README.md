## 🌐 About the Project

This project is a responsive personal portfolio website built using HTML, CSS and JavaScript. It introduces me, showcases my skills and projects, and provides contact information.

## 🚀 Features

- Home and introduction section
- About Me
- Education details
- Technical and non-technical skills
- Projects showcase
- Hobbies and interests
- Achievements
- Contact form with JavaScript validation
- Dark and light theme toggle
- Interactive navigation
- Responsive layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
